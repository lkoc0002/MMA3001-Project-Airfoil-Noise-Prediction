## Engineering Question
How accurately can the sound pressure level generated by a NACA 0012 airfoil be predicted from its operating parameters using machine learning methods?

## Dataset
The project uses the UCI Airfoil Self-Noise dataset containing 1,503 experimental observations.

### Inputs
- Frequency (Hz)
- Angle of attack (°)
- Chord length (m)
- Free-stream velocity (m/s)
- Displacement thickness (m)

### Output
- Sound pressure level (dB)
